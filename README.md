# AppLockTimer

스마트폰 사용 습관을 스스로 관리할 수 있도록 도와주는 **앱 사용시간 제한 앱**이에요.
> ⚠️ **Android 전용 앱입니다.** iOS(아이폰)에서는 사용하실 수 없어요. (자세한 이유는 아래 [플랫폼 안내](#플랫폼-안내) 참고)

---

## 주요 기능

### ⏱ 하루 사용 시간 제한
원하는 앱을 골라 하루 사용 시간을 설정하면, 설정한 시간이 지나는 순간 자동으로 잠겨요. 설정한 시간은 매일 자정에 초기화돼요.

### 📅 요일별 설정
평일과 주말, 또는 요일마다 각각 다른 사용 시간을 따로 지정할 수 있어요. 예를 들어 "평일은 30분, 주말은 1시간"처럼 유연하게 관리할 수 있어요.

### 🌙 휴식 시간 설정
공부, 수면, 집중이 필요한 시간대를 요일별로 지정해두면, 그 시간 동안은 선택한 앱을 아예 실행할 수 없어요. 자정을 넘기는 시간대(예: 22:00~07:00)도 지원해요.

### 🔒 비밀번호 보호
4자리 비밀번호로 제한 설정을 보호해서, 스스로 정한 규칙을 손쉽게 어기지 못하도록 도와줘요.

### 🔋 안정적인 백그라운드 감시
포그라운드 서비스로 앱 사용을 지속적으로 감시하고, 기기를 재부팅해도 감시가 자동으로 다시 시작돼요. 배터리 최적화 예외 설정도 앱 안에서 바로 안내해줘요.

---

## 개인정보 처리

이 앱은 설치된 앱 목록, 사용 시간, 사용자가 설정한 제한 정보를 **기기 내부에만 저장**하며, 어떠한 외부 서버로도 전송하지 않아요. 별도의 회원가입이나 계정 시스템도 없어요.

자세한 내용은 [개인정보처리방침](https://qeenking.github.io/App_lock_timer/)에서 확인할 수 있어요.

## 플랫폼 안내

이 앱의 핵심 기능은 Android 전용 시스템 API를 기반으로 만들어졌어요.

- 앱별 사용 시간 조회 — Android `UsageStatsManager`
- 제한 초과 시 잠금 화면 표시 — Android `SYSTEM_ALERT_WINDOW`(다른 앱 위에 표시) 권한
- 백그라운드 감시 — Android Foreground Service, `BOOT_COMPLETED` 브로드캐스트

iOS는 이런 형태의 시스템 접근을 지원하지 않고, 비슷한 기능을 구현하려면 Apple의 Screen Time API(`FamilyControls`, `ManagedSettings`, `DeviceActivity`)를 별도로 신청·승인받아 완전히 다른 방식으로 새로 개발해야 해요. 그래서 이 저장소의 코드는 **Android에서만 동작**해요.
